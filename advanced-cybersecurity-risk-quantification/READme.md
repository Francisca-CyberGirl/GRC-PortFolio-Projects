# Advanced Cybersecurity Risk Quantification

This project presents a full cybersecurity risk quantification assessment carried out for SecureMobile, a mobile banking platform.

The task focused on identifying high-impact cybersecurity risks, translating them into measurable financial exposure, and recommending security controls based on cost, effectiveness, and return on investment.

The goal was to move beyond technical findings and show what these risks mean in financial and operational terms.

## Project Structure

- **documentation/** → Full report and analysis
- **technical-evidence/** → Raw calculations, supporting worksheets, and source files
- **screenshots-media/** → Charts, visuals, and screenshots used in the lab

## Key Focus Areas

- Quantitative Risk Analysis
- Annualized Loss Expectancy (ALE)
- Cost-Benefit Analysis
- Return on Investment (ROI)
- Risk Treatment Planning
- Executive Risk Reporting

## Key Risks Assessed

- API Authentication Bypass
- Database Injection
- Session Hijacking

## Recommended Controls

- API Security Gateway
- Web Application Firewall (WAF)
- Multi-Factor Authentication (MFA)

## Outcome

This assessment shows how targeted security investments reduce financial exposure, improve resilience, and support stronger business decisions.
