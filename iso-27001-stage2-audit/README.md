# ISO 27001 Stage 2 Audit Assessment

## Overview

This project documents an ISO 27001 Stage 2 audit assessment conducted against a financial technology organization.

The assessment focused on evaluating the effectiveness of Information Security Management System (ISMS) controls, reviewing evidence, identifying nonconformities, assessing corrective actions, and determining overall certification readiness.

The review covered governance controls, personnel security, physical security, vulnerability management, and risk treatment implementation.

## Objectives

- Evaluate the effectiveness of selected ISMS controls.
- Identify and classify audit findings.
- Assess implementation of risk treatment activities.
- Review corrective action effectiveness.
- Develop an evidence-based audit conclusion.
- Present recommendations for improvement.

## Key Findings

### Major Nonconformity

- Approved biometric access controls for the server room had not been implemented despite being identified within the organization's risk treatment plan.

### Nonconformities

- Incomplete evidence of employee background screening.
- Information Security Policy had not undergone periodic review.

### Conformity

- Penetration testing activities were performed as planned.
- Critical vulnerabilities were remediated within established response timelines.
